# 短剧 Shots Prompt 写作手册（抽卡师）

把剧本里的**一个 Beat（节拍）**，写成一条 AI 能稳定生成、15 秒以内的视频提示词。这是抽卡师每天在做的核心交付物。

> 它在整条流水线里的位置：`ai-short-drama-storyboard` skill 负责流水线层面（体量测算 → 定集数时长 → 切 Beat → 建 Spatial Bible → 备资产），这个 skill 接手最后一步——**把已经切好的单个 Beat 落成提示词文本**。如果任务还停在"这场戏要做几集/怎么切 Beat"，先用那个 skill。

## 一条核心矛盾（所有规则都从这里来）

AI 是"每次独立调用、没有上下文记忆、倾向走最省事捷径"的生成器。剧本却是连续叙事。手册里几乎每条规则，都是在弥合这条矛盾——所以空间、视线、走位、音色必须在**每一条** prompt 里完整重写，不能依赖"跨 Beat 的持续效果"，也不能用"同上"。知道规则背后的原因，才能在手册没覆盖的新情况里判断对。

## 提示词八区块标准结构（每条都按这个顺序）

```
[REFERENCE]        角色资产图 + 站位参考图（+ 多角色 reference audio 映射）
[SPATIAL ANCHOR]   空间锚点与位置关系（有站位图则精简，图承载空间）
[GOAL]             这条 Beat 的核心戏剧目的（1-3 句）
[CHARACTER STATES] 每个入画角色当下的情绪状态（非说话角色也要写）
[SHOT PLAN]        分镜方案：时间戳 + 机位 + 动作 + 视线
[DIALOGUE]         仅实际开口说的台词（V.O. 绝不放这里）
[EXPORT]           输出格式 + 音频说明 + 口音锁定
[NEGATIVE]         明确禁止 AI 默认会生成、但你不想要的一切
```

## 五条贯穿全程的硬规则（每条 prompt 都适用，违反必出问题）

1. **外貌代替人名。** AI 不认名字，只认服装外貌。写 `【a Hispanic man in black tuxedo — dark wavy hair】`，不写 `Julian`。服装/造型一旦变化（戴上王冠、衣服被撕），后续所有 Beat 立即换成新描述。

2. **机位用空间坐标，不用电影术语。** 不写 "POV""正反打"，改用四要素：摄影机在哪 / 朝哪个方向拍 / 主体面朝哪 / 背景是什么（背景是验证机位对不对的关键）。想拍低位角色正面 → 机位放在比他高、在他和目标之间的位置朝下拍，而不是放在他旁边（那样他会背对镜头）。

3. **抽象情绪必须翻译成物理表现。** AI 渲染不了"悲伤""崩溃"，要写成 `a fine tremor in her hands, voice steady, jaw does not quiver, eyes dry`。非说话角色也得给情绪指令，否则会变雕像。

4. **走位写三要素：移动方向 + 移动中面朝哪 + 停止后面朝哪。** 光写 "steps back" 会被 AI 解读成"先转身再后退"（背对对方）。要补 `body does NOT turn, face and chest remain toward [对方] throughout`。

5. **NEGATIVE 永远不能省，越复杂越重要。** 它是保险层。生成前逐条自问：AI 最可能把角色渲染成什么样、哪个走位会被误解、有没有不该出现的道具、背景该是什么、有没有 V.O./O.S. 要锁口型、场景会不会触发英音、每个说话角色绑没绑 reference audio。

## 写完一条 prompt 的自检（交付前过一遍）

- [ ] 所有角色用**外貌**指代，且服装状态是当前 Beat 的最新状态？
- [ ] 每个机位都说清了"摄影机在哪 / 朝哪拍 / 主体面朝哪 / 背景是什么"？
- [ ] 正反打的视线在同一轴上、方向相反，没有看错角色或看镜头？
- [ ] 每个走位都写了三要素，需要锁身体朝向的地方锁了？
- [ ] 情绪是物理化描述，不是抽象词？非说话角色也有当下情绪？
- [ ] V.O. 在 EXPORT 的 Audio 而非 DIALOGUE，且 NEGATIVE 锁了口型？
- [ ] 正式/宫廷场景在 EXPORT + NEGATIVE 双锁了美式口音？
- [ ] 每个开口的角色都绑了对应 reference audio（若工具支持多条）？
- [ ] NEGATIVE 把上面每一类该锁的都锁了？
- [ ] 终极标准：**你自己读完能脑补出一个清晰的镜头画面吗？** 不能就说明哪里还不够具体。
